# Правила владельца

Файл читается в начале аудита. Всё, что здесь записано, сильнее дефолтов каталога, но не отменяет факт-замок.

Формат: одна правка — одна строка. Дата, что было, как надо, почему.

- 2026-08-27 · «функционал» не менять на «функциональность»: в 1С-среде слово устоялось.
- 2026-08-27 · термины из `references/terms-it-1c.md` для читателя-коллеги не расшифровывать.
- 2026-08-27 · длинное тире оставлять; дефис вместо тире не ставить. И наоборот: авторский дефис « - » на тире не менять, если не просили — это типографика, не читаемость.
- 2026-08-27 · паспорт голоса владельца — `voice-author.md` (снят с 16 статей на Хабре). Для его текстов он сильнее `references/voice.md`.
- 2026-08-27 · «не только… но и» — не дефект, линтер его больше не помечает. Не «лечить» перечислением.
- 2026-08-27 · вводные «по сути», «собственно», «в любом случае», «вцелом», «конечно», «пожалуй» — голос владельца. Оставлять; убирать только два в одной фразе.
- 2026-08-27 · усилители «существенно», «сильно», «прямо», «лютый / жуткий», «в разы», «x5–x10» — голос владельца, не вычищать.
- 2026-08-27 · «в данном случае», «на данный момент», «на текущий момент времени» — устойчивые обороты, не канцелярит. Остальные «данный» → «этот» — можно.
- 2026-08-27 · структура статьи «лид одной строкой → итог сразу → условия → разбор по ярлыкам → Итого списком → подпись с каналом» — не трогать. Подпись «подписывайтесь на мой канал https://…» без точки — не обрыв.
- 2026-08-27 · термины по-английски и с заглавной (Workflow, Production, Spec-Driven, Rules, MCP) не переводить и не приводить к строчным; «сети» (= нейросети), «курсор» (= Cursor), «китайцы» (= китайские модели) не «поправлять».
- 2026-08-27 · «давайте посмотрим / разберём» в туториале и «нужно понимать, что» перед предупреждением — допустимы; линтер помечает их `-weak`, решать по контексту.

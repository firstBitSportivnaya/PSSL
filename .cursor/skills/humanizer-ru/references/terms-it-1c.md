# Термины ИТ и 1С: что не канцелярит

Отглагольные существительные — главный признак канцелярита. Но в 1С половина механизмов называется отглагольными: «проведение», «заполнение», «обработка». Это имена сущностей платформы. Их не переводят на «человеческий», не заменяют глаголами и не расшифровывают коллегам.

Граница простая:

| Термин (не трогать) | Канцелярит (править) |
|---|---|
| проведение документа | осуществить проведение документа → провести документ |
| обработка проведения | в рамках обработки проведения осуществляется формирование → обработка проведения формирует |
| заполнение по умолчанию | производится заполнение по умолчанию → заполняется по умолчанию |
| формирование движений | обеспечивает формирование движений → формирует движения |
| обмен данными | осуществляет обмен данными → обменивается данными / выгружает |
| регламентное задание | запуск регламентного задания производится по расписанию → регламентное задание запускается по расписанию |
| настройка прав доступа | реализована возможность настройки прав → права настраиваются |
| закрытие месяца | процедура осуществления закрытия месяца → закрытие месяца |

Правило: термин из двух-трёх слов оставляем целиком; всё, что налипло вокруг («осуществление», «в рамках», «производится», «обеспечивает возможность»), — снимаем.

## Разработка с ИИ

Отглагольные, которые здесь — имена механизмов: генерация кода / метаданных / форм / ТЗ, сжатие контекста, очистка контекстного окна, экономия токенов, семантический / векторный / полнотекстовый поиск, индексация репозитория, переключение мастера, улучшение промпта (Enhance Prompt), принятие изменений (accept diff), следование инструкциям, управление контекстом / памятью / задачами, масштабирование, шардирование, секционирование, профилирование, резервирование, кластеризация.

Термины по-английски, которые не переводят: MCP, MCP-сервер, tool, Rules, Skills, Workflow, Spec-Driven / SDD, Custom Modes, Memory Bank, PRD, harness, reasoning effort, embedding, RAG, Cache Read, context window, subagent, agentic, benchmark, LMArena, SWE-bench, IDE, CLI, fork, diff, inline edit, background agent, Production, Enterprise, OnPremise, HighLoad, LTS, OpenSource. Рядом те же слова кириллицей — ризонинг, спека, скилл, тул, бенч, агентский режим, сабагент, вайбкодинг, вайбкодер, инференс, эмбеддинг, промпт, токены, контекст — тоже норма для коллег; не унифицировать написание.

Модели и продукты пишут как автор: Claude / Sonnet / Opus, GPT, Gemini, Grok, Qwen, DeepSeek, GLM, Kimi, Cursor, Claude Code, Codex, Kiro, Roo Code, Kilo Code, Cline, Windsurf, TRAE, Zed, Warp, OpenRouter, EDT, конфигуратор. «Сети» в значении «нейросети», «курсор» в значении Cursor, «китайцы» в значении «китайские модели» — жаргон среды.

В посте и статье для коллег — оставлять. В инструкции для бухгалтера или письме заказчику — заменять нейтральным словом: «выкатили» → «выпустили», «упало» → «перестало работать», «костыль» → «временное решение» (здесь как раз канцелярит уместнее жаргона).

## Как читать список

Список не запрещает править фразу вокруг термина. Он запрещает только принимать сам термин за дефект. «Регламентное задание осуществляет запуск обмена» → «регламентное задание запускает обмен»: термин остался, канцелярит ушёл.

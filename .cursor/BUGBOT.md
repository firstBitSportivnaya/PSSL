# Рекомендации по ревью проекта

## Язык ревью

- Всегда делай ревью на русском языке

## Правила

Факты проекта, запреты и правила BSL — `AGENTS.md` (разделы «Запреты» и «Правила BSL»). Замечания сверять с ними.

- Не ревьюить вендорный движок `src/cfe/YAXUnit/**/ЮТ*` — он не правится без задачи на обновление YAxUnit.
- `пбп_Переадресация*` — обёртки над БСП: проверять только, что новые вызовы БСП идут через них, а не напрямую.
- Новые объекты без префикса `пбп_` и машинные пути в коде — блокирующие замечания.

## Runtime

Облачный образ (`.cursor/install.sh`) ставит только BSL Language Server (`bsl-ls`, настройки `.bsl-language-server.json`). Прогон YaXUnit и загрузка конфигурации и расширения — на локальной машине через Unica (skill `pssl-library`), платформа 1С в этот образ не входит.
